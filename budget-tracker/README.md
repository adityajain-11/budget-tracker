# Budget Tracker 💰

A simple Python program to track expenses and visualize spending with a pie chart.

## 🚀 Run Locally in Codespaces

1. Open the repo in **GitHub Codespaces**.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the program:
   ```bash
   python3 budget_tracker.py
   ```

## Features
- Add expenses by category
- View a text summary
- See a pie chart breakdown
- Save/load expenses from CSV
